# Change Report — OpenAI Responses API & Codex Support (Milestone 3)

This document logs all the changes made to implement the OpenAI Responses API & Codex Support in `clasp`.

## Ported Files

We created the `clasp/core/openai_responses` directory and ported all 13 core files from `free-claude-code-main/core/openai_responses/` to `clasp/core/openai_responses/`:
- `__init__.py` - Core package initializer.
- `adapter.py` - Facade class (`OpenAIResponsesAdapter`) for protocol translation.
- `anthropic_sse.py` - Parsing Anthropic SSE events.
- `errors.py` - Standard OpenAI-compatible error shapes.
- `events.py` - Formatting OpenAI Responses SSE events.
- `ids.py` - Unique UUID-based identifiers.
- `input.py` - Translating OpenAI Responses request payloads to Anthropic Messages format.
- `items.py` - Constructing Response output items (messages, reasoning).
- `reasoning.py` - Mapping reasoning effort and thinking blocks.
- `stream.py` - Async generator translation pipeline.
- `stream_state.py` - Block-indexed state assembler for translating events in real-time.
- `tools.py` - Mapping and namespacing function tools.
- `usage.py` - Token estimation helpers using `tiktoken`.

All relative imports and references in these files were updated to target `clasp.core.openai_responses` absolute paths.

## Modified Files

### 1. `clasp/api/proxy_routes.py`
- Imported `OpenAIResponsesAdapter`.
- Implemented the `POST /v1/responses` endpoint:
  - Requires Bearer token verification using the existing `Depends(_verify_bearer)` dependency.
  - Ensures the request body has `stream = True` (rejecting non-streaming requests with a `400 Bad Request` code and error payload).
  - Converts request payload to Anthropic Messages payload using `OpenAIResponsesAdapter.to_anthropic_payload()`.
  - Dispatches the translated payload to `handle_request(..., stream=True)`.
  - Streams the translated SSE events back to the client using `StreamingResponse`, yielding the translated SSE events generated by `iter_sse_from_anthropic()`.

### 2. `clasp/core/openai_responses/codex_catalog.py`
- Implemented Codex-compatible model catalog generation (`build_codex_model_catalog`, `write_codex_model_catalog`, and `update_codex_model_catalog`).
- Generates a local catalog at `~/.fcc/codex-model-catalog.json` listing all active CLASP model configurations.

### 3. `clasp/providers/registry.py`
- Modified `refresh_model_lists` to trigger the Codex model catalog generation and write it to `~/.fcc/codex-model-catalog.json` upon startup and/or models list refresh.

## Tests Added

### 1. `tests/unit/test_responses.py`
- Created a comprehensive test suite verifying:
  - Bearer token authentication and rejection.
  - Rejecting requests with `stream=False` or omitted.
  - Correct request payload conversion and SSE streaming translation (mocking the service layers).
  - Correct Codex model catalog generation structure and file persistence.
