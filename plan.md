# plan.md — CLASP: Claude API Switching Proxy

> **CLASP** (Claude API Switching Proxy) is a rate-limit-aware, multi-provider local proxy
> that lets Claude Code use free-tier OpenAI-compatible APIs from NVIDIA NIM, Gemini,
> Cerebras, Groq, Fireworks, OpenRouter, and more — without ever seeing a 429 error.
>
> Two commands. One for humans. One for Claude.
> ```
> clasp server    # Start proxy + open config UI in browser
> clasp claude    # Launch Claude Code through the proxy
> ```

## 1. Design Principles

**P1 — Transparency.** Claude Code must never know it is talking to a non-Anthropic provider.
All protocol translation happens inside the proxy. The client sees a standard Anthropic Messages
API at all times.

**P2 — Never propagate 429.** A 429 from any upstream provider is caught and absorbed. Claude
Code sees either a slightly delayed response or seamless failover — never a broken session.

**P3 — Pre-emptive limiting, not reactive.** Track usage locally and enforce soft thresholds
before hitting provider limits. A 429 from upstream is the fallback, not the plan.

**P4 — Free-tier first.** Every design decision optimizes for stretching free quotas. Paid
features are optional add-ons, not defaults.

**P5 — Zero-config quickstart.** One command (`clasp server`) opens a browser. Paste one
API key. Click Apply. Then `clasp claude`. Done in under 90 seconds.

**P6 — UI over YAML.** Users configure everything via the web UI. `config.yaml` is
auto-generated by the UI, not hand-edited. The YAML is the source of truth on disk;
the UI is just a face for it.

**P7 — Stateful across restarts.** Rate limit state, cooldown timers, and usage counters
survive proxy restarts. A reboot doesn't reset quotas.

**P8 — Session continuity.** `clasp claude` is a transparent wrapper around the real `claude`
binary. All Claude Code flags (`--resume`, `--continue`, `--print`, `--no-update`) pass
through unchanged.

## 2. Tech Stack

| Layer | Choice | Reason |
|---|---|---|
| Language | Python 3.11+ | asyncio handles concurrent SSE + queue naturally |
| Web framework | FastAPI + Uvicorn | Native async, SSE via StreamingResponse, serves static UI |
| Frontend | HTML + Tailwind CSS (CDN) + Alpine.js (CDN) | No build step, ships as static files, reactive UI |
| Package manager | `uv` | Fast, modern, lockfile support |
| Rate limiting | Token Bucket per (provider, key) | Mathematically correct for RPM + TPM |
| Token estimation | `tiktoken` (cl100k_base) | Good cross-model approximation |
| Queue | `asyncio.PriorityQueue` | Native async, no extra dep |
| Cache | SQLite (`aiosqlite`) + in-memory LRU | Persistent + fast hot path |
| Config storage | YAML (`ruamel.yaml`) | Round-trip safe, comment-preserving |
| Config validation | `pydantic-settings` v2 | Type-safe, validated at every load |
| Config hot-reload | `watchfiles` | File watcher, signals live config updates |
| TUI | `rich` | Live panel when running in terminal |
| Logging | `loguru` | Structured, colored, sink-configurable |
| HTTP client | `httpx` | Async, streaming, timeout control |
| Type checking | `ty` (Astral) | Fast, same toolchain as ruff |
| Formatting | `ruff` | Fast, opinionated |
| Testing | `pytest` + `pytest-asyncio` | Async test support for queue/SSE tests |

## 3. CLI Command Surface

All commands live under the `clasp` entry point.

### `clasp server`

```
clasp server [OPTIONS]

Start the CLASP proxy and open the configuration UI in the default browser.

Options:
  --port INTEGER          Proxy port (default: 8082)
  --host TEXT             Bind address (default: 127.0.0.1)
  --no-browser            Start server without opening browser
  --live                  Show rich TUI live panel in terminal
  --config PATH           Path to config.yaml (default: ~/.clasp/config.yaml)
  --debug                 Enable debug logging

Behavior:
  1. Check if server already running (PID file at ~/.clasp/clasp.pid).
  2. If already running: print "CLASP already running at http://127.0.0.1:8082"
     and open browser to existing instance.
  3. If not running:
     a. Load and validate config.yaml.
     b. Bind FastAPI to host:port.
     c. Write PID file.
     d. Wait until /health responds (max 5s).
     e. Open browser to http://127.0.0.1:8082 (unless --no-browser).
     f. Print startup summary to terminal.

Startup terminal output:
  ◆ CLASP v1.0.0 starting...
  ✓ Config loaded: ~/.clasp/config.yaml
  ✓ Providers: NIM (2 keys), Gemini, Cerebras, Groq  [Ollama: not detected]
  ✓ Proxy running at http://127.0.0.1:8082
  ✓ Config UI open at http://127.0.0.1:8082
  → Run `clasp claude` in another terminal to start coding.
  Press Ctrl+C to stop.
```

### `clasp claude`

```
clasp claude [CLAUDE_FLAGS...]

Launch Claude Code connected to the CLASP proxy.
All flags after `clasp claude` are passed directly to the `claude` binary.

Usage examples:
  clasp claude                          # Fresh session
  clasp claude --resume abc123def456    # Resume specific session by ID
  clasp claude --continue               # Resume most recent session
  clasp claude --print "fix this bug"   # Non-interactive single prompt
  clasp claude --no-update              # Skip Claude Code update check

Behavior:
  1. Check if CLASP server is running. If not: warn and optionally auto-start.
  2. Read config to get server port and api_key.
  3. Set environment variables:
       ANTHROPIC_BASE_URL=http://127.0.0.1:{port}
       ANTHROPIC_AUTH_TOKEN={config.server.api_key}
       ANTHROPIC_API_KEY={config.server.api_key}
       CLAUDE_CODE_AUTO_COMPACT_WINDOW=190000
       CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1
       CLASP_SESSION=1
  4. exec the real `claude` binary with all passed flags.
     exec replaces the clasp process. No subprocess wrapper.
     Ctrl+C, signals, and terminal raw mode all work natively.

Session passthrough:
  clasp claude --resume abc123  →  exec: claude --resume abc123
  clasp claude --continue       →  exec: claude --continue
  Any unknown flag passes through unchanged.
```

### `clasp status`

```
clasp status [--json]

Print one-line proxy status. Designed for tmux status bar integration.

Normal output:
  [CLASP] NIM(28/40 rpm)→Gemini | Queue:0 | Keys:3/4 healthy | 1.2k req today

JSON output (--json):
  {"status":"healthy","active_provider":"nvidia_nim","rpm_used":28,"rpm_limit":40,
   "queue_depth":0,"healthy_keys":3,"total_keys":4,"requests_today":1240}

If server not running:
  [CLASP] not running — start with: clasp server
```

### `clasp stop`

```
clasp stop
Gracefully stop the running CLASP server.
Reads PID from ~/.clasp/clasp.pid, sends SIGTERM, waits for clean exit.
Saves rate limit state to disk before shutdown.
```

### `clasp reset [PROVIDER]`

```
clasp reset [PROVIDER]
Reset cooldown state. Calls POST /internal/reset/{provider} on the running server.

  clasp reset              # Reset all providers
  clasp reset nvidia_nim   # Reset only NIM
```

### `clasp init`

```
clasp init
Interactive first-time setup wizard. Creates ~/.clasp/config.yaml with sane defaults.
Asks: primary provider, API keys. Then auto-launches `clasp server`.
```

## 5. Web UI Specification

The web UI is the configuration, monitoring, and management interface. It opens automatically
when `clasp server` starts. All configuration that would otherwise require editing YAML is
done here. Served by FastAPI from the same port as the proxy (`http://127.0.0.1:8082`).

### Technology

- `index.html` + `app.js` + `style.css` — no build step, no Node.js
- Alpine.js v3 from CDN for reactivity
- Tailwind CSS v3 from CDN Play for styling
- Native browser `EventSource` for live SSE dashboard updates
- All config writes: `POST /internal/config` → validate → atomic write → hot-reload

### Save & Apply Flow

1. User edits config in UI → changes staged (yellow borders, "● Unsaved changes" in header).
2. User clicks [Save & Apply].
3. `POST /internal/config` with full config JSON.
4. Server validates via Pydantic. Returns 422 with errors if invalid.
5. If valid: atomic write (`config.yaml.tmp` → rename), signal hot-reload.
6. Return `{"status": "ok", "reloaded_at": "..."}`.
7. UI shows green toast: "Config saved and applied ✓".

Key masking round-trip: UI receives masked keys (`nvapi-***fG9a`). On save, server detects
masked values (contain `***`) and restores originals from the in-memory settings.

## 8. Request Flow End-to-End

```
Claude Code → POST /v1/messages (Authorization: Bearer freecc, stream: true)

  [1] proxy_routes.py
      Validate Bearer token. Parse body. Generate request_id (UUID).

  [2] optimize.py
      /v1/models?  → return static list. Done.
      /count_tokens? → tiktoken estimate. Done.
      Trivial probe (max_tokens≤5)? → local canned response. Done.

  [3] response_cache.py
      Hash request. Memory LRU hit? → return instantly. Done.
      SQLite hit (within TTL)? → warm to memory, return. Done.
      Cache miss → continue.

  [4] detect.py
      Classify: INTERACTIVE|BACKGROUND|LONG_CONTEXT|THINK|TOOL_USE|VISION
      Set priority (0=INTERACTIVE, 1=TOOL_USE, 2=BACKGROUND).
      Estimate tokens via tiktoken.

  [5] selector.py
      Apply by_type override if exists.
      Walk provider_chain:
        skip: disabled, COOLING_DOWN, circuit OPEN.
        check: capability match (tools? vision? context size?).
        try: key_pool.pick_key(estimated_tokens).
        first pass → (provider, key, key_index).
      No provider → go to [6].

  [6] queue/manager.py  (only if no provider available)
      Enqueue with priority.
      SSE hold: send ": keep-alive\n\n" every 15s.
      drain_task retries selector every 1s.
      On provider available → dispatch, resolve Future.
      If wait > max_queue_wait_seconds → yield error event.

  [7] optimizer/
      system_prompt.py: dedup, trim for small-context providers.
      context_pruner.py: prune history if over context limit.

## 10. Phase 2 — Rate Limit Engine

**Goal:** Pre-emptive soft-threshold switching. Never hit a hard limit by design.

### Token Bucket (`ratelimit/bucket.py`)

```python
class TokenBucket:
    """
    Dual-dimension token bucket: RPM + TPM tracked separately.
    Lazy refill on each access + background refill task every 1s.
    asyncio.Lock for concurrency safety across simultaneous requests.
    """
    def __init__(self, rpm_limit: int, tpm_limit: int | None,
                 soft_threshold: float = 0.80):
        self.rpm_capacity = rpm_limit
        self.rpm_tokens = float(rpm_limit)           # Start full
        self.rpm_refill_rate = rpm_limit / 60.0      # per second
        self.tpm_capacity = tpm_limit                # None = unlimited
        self.tpm_tokens = float(tpm_limit or 0)
        self.tpm_refill_rate = (tpm_limit or 0) / 60.0
        self.soft_threshold = soft_threshold
        self._lock = asyncio.Lock()
        self._last_refill = time.monotonic()

    async def can_consume(self, estimated_tokens: int = 0) -> bool:
        async with self._lock:
            self._refill()
            rpm_ok = self.rpm_tokens >= 1.0
            # Under soft threshold means enough headroom remains
            above_soft = self.rpm_tokens < (self.rpm_capacity * (1.0 - self.soft_threshold))
            tpm_ok = self.tpm_capacity is None or self.tpm_tokens >= estimated_tokens
            return rpm_ok and not above_soft and tpm_ok

    async def consume(self, estimated_tokens: int = 0) -> None:
        async with self._lock:
            self._refill()
            self.rpm_tokens = max(0.0, self.rpm_tokens - 1.0)
            if self.tpm_capacity is not None:
                self.tpm_tokens = max(0.0, self.tpm_tokens - estimated_tokens)

    async def consume_actual(self, actual: int, estimated: int) -> None:
        delta = actual - estimated
        if self.tpm_capacity is not None and delta != 0:
            async with self._lock:
                self.tpm_tokens = max(0.0, self.tpm_tokens - delta)

    def seconds_until_available(self) -> float:
        deficit = max(0.0, 1.0 - self.rpm_tokens)
        return deficit / self.rpm_refill_rate if self.rpm_refill_rate > 0 else 60.0

    @property
    def rpm_used(self) -> int:
        return max(0, int(self.rpm_capacity - self.rpm_tokens))

    def _refill(self) -> None:
        now = time.monotonic()
        elapsed = now - self._last_refill
        self.rpm_tokens = min(self.rpm_capacity,
                              self.rpm_tokens + elapsed * self.rpm_refill_rate)
        if self.tpm_capacity is not None:
            self.tpm_tokens = min(self.tpm_capacity,
                                  self.tpm_tokens + elapsed * self.tpm_refill_rate)
        self._last_refill = now
```

### Circuit Breaker (`ratelimit/circuit_breaker.py`)

```
States: CLOSED → OPEN → HALF_OPEN

Trip conditions (any):
  • 3 consecutive 429 responses
  • 5 consecutive timeouts
  • Error rate > 50% over last 10 requests (minimum 5 seen)

OPEN → HALF_OPEN: after cooldown_seconds (doubles on repeated trips, max 600s)
HALF_OPEN + 1 test request:
  • success → CLOSED, reset counters
  • failure → OPEN, double cooldown again
```

### Cooldown (`ratelimit/cooldown.py`)

```python
def on_429(self, provider: str, key_index: int,
           retry_after_header: str | None) -> float:
    """Returns seconds to wait. Parses Retry-After header, else exponential backoff."""
    if retry_after_header:
        seconds = self._parse_retry_after(retry_after_header)
        seconds = min(seconds, 600)   # Cap at 10 minutes regardless of header
    else:
        n = self._get_failure_count(provider, key_index)
        base = self._catalog[provider].backoff_base_seconds
        seconds = min(base * (2 ** n), 600)

    recovery_at = time.monotonic() + seconds
    self._set_cooling(provider, key_index, recovery_at)
    self._increment_failure_count(provider, key_index)
    asyncio.get_event_loop().call_later(seconds, self._re_enable, provider, key_index)
    return seconds

def _parse_retry_after(self, value: str) -> float:
    try:
        return float(value)       # Integer seconds
    except ValueError:
        pass
    try:
        import email.utils
        from datetime import datetime, timezone
        dt = email.utils.parsedate_to_datetime(value)
        return max(0.0, (dt - datetime.now(timezone.utc)).total_seconds())
    except Exception:
        return 60.0
```

## 11. Phase 3 — 429 Absorber + Priority Queue

**Goal:** Zero 429 errors reach Claude Code. The core product differentiator.

### 429 Absorber (`queue/absorber.py`)

```python
async def on_upstream_429(
    request: AnthropicRequest,
    failed_provider: str,
    failed_key_index: int,
    retry_after_header: str | None,
) -> AsyncGenerator[str, None]:

    # 1. Update state
    wait_s = cooldown.on_429(failed_provider, failed_key_index, retry_after_header)
    circuit_breakers[failed_provider][failed_key_index].record_429()

    # 2. Immediate failover
    selection = await selector.select(request, exclude={failed_provider})
    if selection:
        provider, key, key_idx = selection
        async for chunk in provider.stream(request, key=key, key_index=key_idx):
            yield chunk
        return

    # 3. No failover — queue
    future: asyncio.Future = asyncio.get_event_loop().create_future()
    await queue_manager.enqueue(QueuedRequest(
        request=request, future=future,
        priority=request.priority, enqueued_at=time.monotonic()
    ))
    async for chunk in sse_hold.hold_until_resolved(future, settings.max_queue_wait_seconds):

### SSE Hold-Open (`queue/sse_hold.py`)

```python
async def hold_until_resolved(future: asyncio.Future, max_wait: int) -> AsyncGenerator[str, None]:
    start = time.monotonic()
    while not future.done():
        try:
            await asyncio.wait_for(asyncio.shield(future), timeout=15)
        except asyncio.TimeoutError:
            elapsed = int(time.monotonic() - start)
            yield f": keep-alive elapsed={elapsed}s\n\n"
            if time.monotonic() - start > max_wait:
                yield _error_event("All providers rate-limited. Try again shortly.")
                return
    if future.exception():
        yield _error_event(str(future.exception()))
        return
    for chunk in future.result():
        yield chunk

def _error_event(msg: str) -> str:
    payload = json.dumps({"type":"error","error":{"type":"overloaded_error","message":msg}})
    return f"event: error\ndata: {payload}\n\n"
```

### Priority Queue Drain (`queue/manager.py`)

```python
async def drain_task(self) -> None:
    """Background coroutine. Runs forever. Dispatches queued requests as providers recover."""
    while True:
        try:
            _priority, _ts, req = await self._q.get()
            selection = None
            while selection is None:
                selection = await selector.select(req.request)
                if selection is None:
                    if time.monotonic() - req.enqueued_at > self.max_wait_seconds:
                        req.future.set_exception(QueueTimeoutError())
                        self._q.task_done()
                        break
                    await asyncio.sleep(1)
            else:
                provider, key, key_idx = selection
                chunks = []
                try:
                    async for chunk in provider.stream(req.request, key=key, key_index=key_idx):
                        chunks.append(chunk)
                    req.future.set_result(chunks)
                except Exception as e:
                    req.future.set_exception(e)
                finally:
                    self._q.task_done()
        except Exception as e:
            log.error("drain_task error", exc=str(e))
            await asyncio.sleep(1)
```

Priority levels: `0=INTERACTIVE` (user typed something), `1=TOOL_USE` (tool call mid-session),
`2=BACKGROUND` (file indexing, summarization). Under pressure, interactive requests always win.

## 12. Phase 4 — Multi-Key Rotation

**Goal:** N keys per provider → effectively multiply free quota N times.

### Key Pool (`ratelimit/key_pool.py`)

```python
class KeyPool:
    def __init__(self, provider_name: str, keys: list[str], profile: ProviderProfile):
        self.provider_name = provider_name
        self.keys = keys
        self.buckets = [TokenBucket(profile.rpm_limit, profile.tpm_limit,
                                    profile.rpm_soft_threshold) for _ in keys]
        self.circuit_breakers = [CircuitBreaker(profile) for _ in keys]
        self._rr = 0
        self._lock = asyncio.Lock()

    async def pick_key(self, estimated_tokens: int = 0) -> tuple[str, int] | None:
        """Round-robin over healthy keys. Returns (api_key, index) or None."""
        async with self._lock:
            for _ in range(len(self.keys)):
                idx = self._rr % len(self.keys)
                self._rr += 1
                cooling = cooldown.is_cooling(self.provider_name, idx)
                cb_ok = self.circuit_breakers[idx].is_closed()
                if not cooling and cb_ok and await self.buckets[idx].can_consume(estimated_tokens):
                    await self.buckets[idx].consume(estimated_tokens)
                    return self.keys[idx], idx
        return None

    def health_summary(self) -> dict:
        return {
            "total": len(self.keys),
            "healthy": sum(
                1 for i in range(len(self.keys))
                if not cooldown.is_cooling(self.provider_name, i)
                and self.circuit_breakers[i].is_closed()
            ),
            "keys": [
                {
                    "index": i, "redacted": _redact(self.keys[i]),
                    "status": self._key_status(i),
                    "rpm_used": self.buckets[i].rpm_used,
                    "rpm_limit": self.buckets[i].rpm_capacity,
                    "recovery_in": cooldown.seconds_until_recovery(self.provider_name, i),
                }
                for i in range(len(self.keys))
            ],
        }

def _redact(key: str) -> str:
    if len(key) <= 8:
        return "***"
    return key[:6] + "***" + key[-4:]
```

## 13. Phase 5 — Multi-Provider Chain & Smart Routing

### Provider Selector (`router/selector.py`)

```python
async def select(
    request: AnthropicRequest,
    exclude: set[str] | None = None,
) -> tuple[BaseProvider, str, int] | None:
    settings = get_settings()
    exclude = exclude or set()

    # Build candidate order. by_type override goes first.
    override_name = (settings.routing.by_type.get(request.type.value) or "").split("/")[0]
    if override_name and override_name not in exclude:
        candidates = [override_name] + [p for p in settings.provider_chain
                                         if p != override_name]
    else:
        candidates = list(settings.provider_chain)

    for provider_name in candidates:
        if provider_name in exclude:
            continue
        cfg = settings.providers.get(provider_name)
        if not cfg or not cfg.enabled:
            continue
        provider = registry.get(provider_name)
        if not provider:
            continue

        # Capability check
        model_slug = model_map.resolve(request, provider_name, settings)
        if not model_slug:
            continue
        caps = capability.get(provider_name, model_slug)
        if request.needs_tools and not caps.supports_tools:
            continue
        if request.needs_vision and not caps.supports_vision:
            continue
        if request.estimated_tokens > caps.max_context_tokens * 0.9:
            continue

        # Key availability
        key_pool = registry.get_key_pool(provider_name)
        result = await key_pool.pick_key(request.estimated_tokens)
        if result:
            api_key, key_idx = result
            return provider, api_key, key_idx

    return None
```

### Model Resolution (`router/model_map.py`)

Matching order: (1) by_type override, (2) tier keyword in model name, (3) default.
`claude-fable-*` matches any model name containing the string "fable".
Returns the model slug portion for the given provider, or None if provider doesn't match.

### `ui/static/app.js` — Complete Alpine.js Application

```javascript
function claspApp() {
  return {
    // UI state
    panel: 'providers',
    dirty: false,
    saving: false,
    toast: { show: false, message: '', type: 'success' },
    logLevel: 'INFO',
    logLines: [],
    sharedPoolTokensText: '',

    // Data
    meta: { version: '1.0.0', status: 'healthy', port: 8082 },
    config: {},
    catalog: {},   // provider_catalog.py data served from /internal/catalog
    live: {},      // Live metrics from SSE

    nav: [
      { id: 'providers', icon: '🔑', label: 'Providers' },
      { id: 'models',    icon: '🎯', label: 'Models' },
      { id: 'dashboard', icon: '📊', label: 'Dashboard' },
      { id: 'routing',   icon: '🔀', label: 'Routing' },
      { id: 'advanced',  icon: '⚙️',  label: 'Advanced' },
      { id: 'logs',      icon: '📋', label: 'Logs' },
    ],

    modelTiers: [
      { key: 'opus',    label: 'claude-opus-*',    hint: 'Most capable' },
      { key: 'sonnet',  label: 'claude-sonnet-*',  hint: 'Balanced' },
      { key: 'haiku',   label: 'claude-haiku-*',   hint: 'Fast & light' },
      { key: 'fable',   label: 'claude-fable-*',   hint: 'Catch-all for new names' },
      { key: 'default', label: 'default',           hint: 'No tier match' },
    ],

    requestTypes: [
      { key: 'think',        label: 'Thinking / reasoning',
        hint: 'Extended thinking enabled' },
      { key: 'long_context', label: 'Long context  (>50k tokens)',
        hint: 'Route to high-context provider' },
      { key: 'background',   label: 'Background tasks',
        hint: 'File indexing, summarization' },
      { key: 'vision',       label: 'Vision / image input',
        hint: 'Route to vision-capable provider' },
    ],

    strategies: [
      { key: 'priority-chain', label: 'Priority Chain',
        description: 'Try providers in order above. Skip unhealthy ones.' },
      { key: 'least-loaded',   label: 'Least Loaded',
        description: 'Always route to provider with the most remaining RPM.' },
      { key: 'cost-aware',     label: 'Cost Aware',
        description: 'Prefer fully-free providers, then free-credit providers.' },
    ],

    async init() {
      await Promise.all([this.loadConfig(), this.loadCatalog()]);
      this.startLiveStream();
      this.startLogStream();
    },

    async loadConfig() {
      const res = await fetch('/internal/config');
      const data = await res.json();
      // Add UI-only fields to each provider
      for (const name in (data.providers ?? {})) {
        const p = data.providers[name];
        p._open = p.enabled;  // Expand enabled providers by default
        p.keys = (p.keys ?? []).map(k => ({
          value: k, _reveal: false, _testing: false, _testResult: null
        }));
      }
      this.config = data;
      this.meta.port = data.server?.port ?? 8082;
      if (data.shared_pool?.auth_tokens) {
        this.sharedPoolTokensText = data.shared_pool.auth_tokens.join('\n');
      }
    },

    async loadCatalog() {
      const res = await fetch('/internal/catalog');
      this.catalog = await res.json();
    },

    startLiveStream() {
      const connect = () => {
        const es = new EventSource('/internal/stream');
        es.onmessage = (e) => {
          this.live = JSON.parse(e.data);
          this.meta.status = this.live.status;
        };
        es.onerror = () => {
          this.meta.status = 'error';
          es.close();
          setTimeout(connect, 3000);  // Reconnect after 3s
        };
      };
      connect();
    },

    startLogStream() {
      const connect = () => {
        const es = new EventSource('/internal/logs/stream');
        es.onmessage = (e) => {
          const line = JSON.parse(e.data);
          this.logLines.push(line);
          if (this.logLines.length > 500) this.logLines.shift();
          this.$nextTick(() => {
            const el = document.getElementById('log-container');
            if (el) el.scrollTop = el.scrollHeight;
          });
        };
        es.onerror = () => { es.close(); setTimeout(connect, 3000); };
      };
      connect();
    },

    markDirty() { this.dirty = true; },

    discardChanges() {
      this.dirty = false;
      this.loadConfig();
    },

    async saveAndApply() {
      this.saving = true;
      try {
        const payload = this._buildPayload();
        const res = await fetch('/internal/config', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(payload),
        });
        if (res.ok) {
          this.dirty = false;
          this.showToast('Config saved and applied ✓', 'success');
          await this.loadConfig();
        } else {
          const err = await res.json();
          this.showToast('Error: ' + (err.detail ?? 'Validation failed'), 'error');
        }
      } catch (e) {
        this.showToast('Network error: ' + e.message, 'error');
      } finally {
        this.saving = false;
      }
    },

    _buildPayload() {
      // Serialize config back to wire format (strip UI-only _fields)
      const cfg = JSON.parse(JSON.stringify(this.config));
      for (const name in (cfg.providers ?? {})) {
        const p = cfg.providers[name];
        p.keys = (p.keys ?? []).map(k => k.value);
        delete p._open;
      }
      return cfg;
    },

    async testKey(providerName, keyValue, keyIndex) {
      const prov = this.config.providers[providerName];
      if (!prov?.keys?.[keyIndex]) return;
      prov.keys[keyIndex]._testing = true;
      try {
        const res = await fetch('/internal/config/test-key', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ provider: providerName, key: keyValue, key_index: keyIndex }),
        });
        prov.keys[keyIndex]._testResult = await res.json();
      } finally {
        prov.keys[keyIndex]._testing = false;
      }
    },

    addKey(providerName) {
      this.config.providers[providerName].keys.push({
        value: '', _reveal: false, _testing: false, _testResult: null
      });
      this.markDirty();
    },

    removeKey(providerName, idx) {
      this.config.providers[providerName].keys.splice(idx, 1);
      this.markDirty();
    },

    removeFromChain(idx) {
      this.config.provider_chain.splice(idx, 1);
      this.markDirty();
    },

    enabledProviders() {
      return Object.keys(this.config.providers ?? {})
        .filter(n => this.config.providers[n].enabled);
    },

    providerStatusText(name) {
      const pd = this.live.providers?.[name];
      if (!pd) return 'OFF';
      return pd.status ?? 'UNKNOWN';
    },

    providerStatusClass(name) {
      const status = this.providerStatusText(name);
      return {
        'bg-green-900 text-green-400':  status === 'HEALTHY',
        'bg-yellow-900 text-yellow-400': status === 'SOFT_LIMIT',
        'bg-orange-900 text-orange-400': status === 'COOLING_DOWN',
        'bg-red-900 text-red-400':      status === 'CIRCUIT_OPEN',
        'bg-gray-800 text-gray-500':    status === 'OFF' || status === 'UNKNOWN',
      };
    },

    filteredLogs() {
      const levels = { DEBUG: 0, INFO: 1, WARNING: 2, ERROR: 3 };
      const minLevel = levels[this.logLevel] ?? 1;
      return this.logLines.filter(l => (levels[l.level] ?? 0) >= minLevel);
    },

    resetModelDefaults() {
      // Fetch defaults from /internal/catalog/defaults and apply
      fetch('/internal/catalog/defaults')
        .then(r => r.json())
        .then(defaults => {
          this.config.routing.models = defaults.models;
          this.config.routing.by_type = defaults.by_type;
          this.markDirty();
        });
    },

    syncSharedTokens() {
      this.config.shared_pool.auth_tokens = this.sharedPoolTokensText
        .split('\n').map(t => t.trim()).filter(Boolean);
      this.markDirty();
    },

    async clearCache() {
      await fetch('/internal/cache/clear', { method: 'POST' });
      this.showToast('Cache cleared', 'success');
    },

    async exportConfig() {
      const res = await fetch('/internal/config/export');
      const yaml = await res.text();
      const blob = new Blob([yaml], { type: 'text/yaml' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url; a.download = 'clasp-config.yaml';
      a.click(); URL.revokeObjectURL(url);
    },

    async importConfig(event) {
      const file = event.target.files[0];
      if (!file) return;
      const text = await file.text();
      const res = await fetch('/internal/config/import', {
        method: 'POST',
        headers: { 'Content-Type': 'text/plain' },
        body: text,
      });
      if (res.ok) {
        await this.loadConfig();
        this.showToast('Config imported ✓', 'success');
      } else {
        this.showToast('Import failed — invalid YAML', 'error');
      }
    },

    formatUptime(seconds) {
      if (!seconds) return '—';
      const h = Math.floor(seconds / 3600);
      const m = Math.floor((seconds % 3600) / 60);
      return h > 0 ? `${h}h ${m}m` : `${m}m`;
    },

# Per-user token bucket (separate from provider buckets)
class PerUserBucket:
    """
    Limits each shared-pool user to per_user_rpm_limit requests/min.
    Separate from provider buckets — applies on top of provider limits.
    """
    def __init__(self, per_user_rpm: int):

                rpm_limit=self.per_user_rpm, tpm_limit=None)

```

### Semantic Cache (`cache/semantic_cache.py`)

Phase 8 optional feature. Caches semantically similar requests.

```python
# Dependencies: sentence-transformers (CPU-only), faiss-cpu
# Model: all-MiniLM-L6-v2 (~80MB, loads at startup)
# Threshold: 0.95 cosine similarity (conservative)

class SemanticCache:
    THRESHOLD = 0.95

    def __init__(self):
        from sentence_transformers import SentenceTransformer
        self.model = SentenceTransformer('all-MiniLM-L6-v2')
        # In-memory FAISS index
        import faiss
        self.index = faiss.IndexFlatIP(384)   # Inner product = cosine on normalized vecs
        self.responses: list[dict] = []

    async def lookup(self, request: AnthropicRequest) -> dict | None:
        query = self._extract_query(request)
        vec = self.model.encode([query], normalize_embeddings=True)
        if self.index.ntotal == 0:
            return None
        D, I = self.index.search(vec, k=1)
        if D[0][0] >= self.THRESHOLD:
            return self.responses[I[0][0]]
        return None

    async def store(self, request: AnthropicRequest, response: dict) -> None:
        query = self._extract_query(request)
        vec = self.model.encode([query], normalize_embeddings=True)
        self.index.add(vec)
        self.responses.append(response)

    def _extract_query(self, req: AnthropicRequest) -> str:
        last_human = [m for m in req.messages if m["role"] == "user"]
        if not last_human:
            return ""
        content = last_human[-1].get("content", "")
        if isinstance(content, str):
            return content[:2000]
        return " ".join(b.get("text", "") for b in content
                        if isinstance(b, dict) and b.get("type") == "text")[:2000]
```

Only enable if measuring significant quota drain from near-duplicate requests.
Startup time penalty: ~3s for model load. Memory: ~300MB for model + index.

## 18. Testing Strategy

### Unit Tests

**`test_bucket.py`:**
- Fill to capacity → `can_consume()` = True.
- Exhaust RPM → `can_consume()` = False.
- Soft threshold: consume to 85% → `can_consume()` = False (above soft limit).
- TPM limit: consume enough tokens → `can_consume(1000)` = False despite RPM available.
- Partial refill: wait `1/refill_rate` seconds → `can_consume()` = True.
- Concurrent consume from 20 tasks → total consumed never exceeds capacity (no races).
- `consume_actual()` correctly adjusts TPM for estimation delta.

**`test_key_pool.py`:**
- 3 keys all healthy → round-robins 0,1,2,0,1,2.
- Key[0] exhausted → picks key[1], then key[2].
- All keys exhausted → returns None.
- Key[1] in cooldown, others healthy → skips key[1].
- `health_summary()` reports correct healthy/total count.

**`test_circuit_breaker.py`:**
- 3 consecutive `record_429()` → state OPEN.
- OPEN + elapsed cooldown → check_recovery() → state HALF_OPEN.
- HALF_OPEN + `record_success()` → state CLOSED, counters reset.
- HALF_OPEN + `record_429()` → state OPEN, cooldown doubled.
- 5 consecutive timeouts → trips to OPEN.
- Mixed errors < threshold → stays CLOSED.

**`test_message_converter.py`:**
- Round-trip: `anthropic_to_openai` → `openai_to_anthropic_response`. Compare fields.
- System message → OpenAI system role (and merge variant for NIM).
- Tool use block → OpenAI `tool_calls` delta sequence → back to Anthropic.
- Tool result → OpenAI `tool` role message → back.
- Base64 image → OpenAI `image_url` → back.
- Thinking block → stripped for non-thinking providers.
- Empty tools array → `tools` key absent from OpenAI payload.
- Multiple content blocks (text + tool_use) → correct parallel emission.

**`test_sse_builder.py`:**
- Text delta chunk → Anthropic `content_block_delta` with `text_delta`.
- First chunk → `message_start` emitted before first `content_block_start`.
- Tool call delta sequence → buffered correctly → Anthropic tool_use blocks.
- `finish_reason: "stop"` → `message_delta` with `stop_reason: "end_turn"` + `message_stop`.
- `finish_reason: "tool_calls"` → `stop_reason: "tool_use"`.
- `finish_reason: "length"` → `stop_reason: "max_tokens"`.
- Malformed SSE chunk → logged, skipped (no crash).

**`test_detect.py`:**
- `max_tokens=1`, 1-message body → `PROBE`.
- `thinking: {type: "enabled"}` → `THINK`.
- Estimated tokens > 50000 → `LONG_CONTEXT`.
- `tools=[...]` present → `TOOL_USE`.
- Image content block present → `VISION`.
- Standard code request → `INTERACTIVE`.
- Background marker patterns → `BACKGROUND`.

**`test_context_pruner.py`:**
- Short history (under limit) → returned unchanged.
- Long history → keeps first 3 + last 10 + all tool messages.
- Truncated section → note message inserted at correct position.
- Tool chain in middle → never dropped.

## 19. Edge Cases & Gotchas

### `clasp claude` `exec` Semantics

Always use `os.execvp()`, not `subprocess.run()`. `exec` replaces the CLASP process:
- Terminal raw mode (arrow keys, multiline input) works natively.
- Ctrl+C goes directly to `claude`, not to a Python wrapper.
- `--resume` and `--continue` work exactly as if the user called `claude` directly.
- Process title shows as `claude`, not `python`.

```python
os.execvp(claude_bin, [claude_bin] + passthrough_args)
# Nothing after this line runs if exec succeeds.
# exec only "fails" if the binary doesn't exist (OSError).
```

### Config Key Masking Round-Trip

UI receives `nvapi-***fG9a`. User doesn't touch the key. Saves. Server receives `nvapi-***fG9a`.
Must detect masked values and restore originals from `get_settings()`:

```python
def restore_redacted(new_cfg: dict, original: Settings) -> dict:
    for pname, pcfg in new_cfg.get("providers", {}).items():
        orig_keys = getattr(original.providers.get(pname), 'keys', [])
        restored = []
        for i, entry in enumerate(pcfg.get("keys", [])):
            # entry is either a string (from CLI) or a dict with .value (from UI)
            value = entry if isinstance(entry, str) else entry.get("value", "")
            if "***" in value:
                restored.append(orig_keys[i] if i < len(orig_keys) else value)
            else:
                restored.append(value)
        pcfg["keys"] = restored
    return new_cfg
```

### Browser Auto-Open Race

`clasp server` starts uvicorn and then immediately tries to open the browser. The server
may not be ready yet. Poll `/health` before opening:

```python
async def open_browser_when_ready(url: str, timeout: float = 8.0) -> None:
    deadline = time.monotonic() + timeout
    async with httpx.AsyncClient() as client:
        while time.monotonic() < deadline:
            try:
                r = await client.get(f"{url}/health", timeout=0.5)
                if r.status_code == 200:
                    webbrowser.open(url)
                    return
            except Exception:
                pass
            await asyncio.sleep(0.2)
    webbrowser.open(url)   # Open anyway — better than silence
```

### PID File Stale Detection

If CLASP crashed without cleanup, a stale PID file exists with a dead PID.
`os.kill(pid, 0)` raises `ProcessLookupError` for dead PIDs — treat stale PID as no server:

```python
def is_server_running(pid_path: Path) -> tuple[bool, int | None]:
    if not pid_path.exists():
        return False, None
    try:
        pid = int(pid_path.read_text().strip())
        os.kill(pid, 0)   # Signal 0 = existence check only
        return True, pid
    except (ValueError, ProcessLookupError):
        pid_path.unlink(missing_ok=True)   # Clean up stale file
        return False, None
    except PermissionError:
        return True, None   # Process exists, we just can't signal it
```

### Mid-Stream 429

A 429 can arrive after SSE has already started. Most providers send 429 before the first
content token (it's a pre-flight check). However if a 429 arrives mid-stream:

- We cannot restart the stream cleanly — Claude Code has already received partial content.
- Best strategy: complete with an Anthropic `error` event, preserve what was streamed.
- Claude Code will typically ask the user to retry; CLASP handles the retry correctly.
- Log it as `outcome: "mid_stream_429"` for visibility.

Phase 1 behaviour: surface error. Phase 3+: if the 429 arrives before the first text
token, absorb and failover. Buffer the first ~200ms of stream before forwarding.

### NVIDIA NIM Model Quirks

`moonshotai/kimi-k2` and `kimi-k2-thinking` have slightly different parameter names for
extended thinking. Handle in `nvidia_nim.py`:

```python
if "kimi" in model and thinking_enabled:
    payload["extra_body"] = {"thinking": {"type": "enabled", "budget_tokens": 8000}}
```

Some NIM models return `"role": "assistant"` in delta frames instead of omitting it.
The SSE builder must tolerate this — it's valid but redundant.

### Gemini Safety Blocks Are Not Rate Limits

`finish_reason: "SAFETY"` from Gemini is a content block, not a 429. Map to:
```json
{"type": "error", "error": {"type": "invalid_request_error",
 "message": "Response blocked by Gemini safety filters. Try rephrasing."}}
```
Do not retry on a different provider. The content itself may be the issue.

### OpenRouter Free Models Must Use `:free` Suffix

Validate in `openrouter.py` at startup. Warn if model slug lacks `:free`:
```python
if not model_slug.endswith(":free"):
    log.warning("OpenRouter model may incur charges", model=model_slug,
                hint="Append ':free' to model slug for free tier")
```

## Appendix B — `clasp claude` Flag Reference

All flags are passed through to the real `claude` binary unchanged:

```
clasp claude                                   — new session
clasp claude --resume <session-id>             — resume by session ID
clasp claude --continue                        — resume most recent session
clasp claude --print "prompt here"             — non-interactive, single prompt
clasp claude -p "prompt" --output-format json  — pipe-friendly JSON output
clasp claude --no-update                       — skip update check
clasp claude --model claude-sonnet-4-5         — force specific model (CLASP maps it)
clasp claude --dangerously-skip-permissions    — skip permission prompts
clasp claude --add-dir /path/to/code           — add directory to context
```

The exec call:
```python
os.execvp(claude_bin, [claude_bin] + passthrough_args)
# exec replaces this process completely.
# Terminal raw mode, Ctrl+C, process signals all work natively.
```
